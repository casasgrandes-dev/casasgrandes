# ADR del cambio — CHG-029

No se crea un ADR nuevo. Este cambio acota la matriz operativa de `SDD-SEC-013` (bajo `ADR-016`) para permitir que el rol `Administrador`, además de `Almacen`, ejecute movimientos manuales de inventario de semilla (`Entrada` y `Salida`) con selección de tamaño y lote en Almacén, manteniendo la bandeja de solicitudes comerciales y la asignación de reservas a pedidos exclusivamente en el rol `Almacen`.
